Yeni Şikayet

Virgülle veya alt alta yazabilirsin. Tam URL yapıştırırsan otomatik domaine indirgenir.
Netcraft formundaki "kim bildiriyor" alanını ve giden maillerin Reply-To adresini belirler. Boş bırakırsan markanın kendi maili kullanılır (ör. betsat için support@betsat.com).
Bu, tam bir şikayet mailinin GÖNDERİLECEĞİ adrestir — host otomatik tespit edilemediğinde veya bildiğin bir adrese ekstra göndermek istediğinde kullan.
▸ GitHub bağlantı ayarları
PAT sadece bu repo için Actions: Read and write izniyle, fine-grained token olarak oluşturulmalı — süresi olan, tek repo'ya kısıtlı bir token kullan. Bu sayfa token'ı hiçbir sunucuya göndermez, sadece GitHub API'ye doğrudan tarayıcından istek atar.

Gönderim Geçmişi

Henüz gönderim yok. İlk şikayetini gönderdiğinde burada görünecek.
GitHub Actions'ta Görüntüle →
Panel, GitHub Actions workflow_dispatch event'ini tetikler. Gerçek gönderim sonucu (mail atıldı mı, hangi host bulundu vb.) birkaç saniye içinde Telegram'a düşer — bu panel sadece tetikleme onayını gösterir, iş GitHub Actions üzerinde asenkron çalışır. Geçmiş bu tarayıcıda kalıcı olarak saklanır (son 100 kayıt).
